# 日本語版personaの翻訳メモ

## 日本語版に合わせたカード

- `seosoyoung.rules.general`。朝鮮王朝風の国の有力な一族に生まれ、異国で魔法を学ぶという設定を保った。口調は丁寧で少し古風な日本語とし、「わたくし」「申します」「伺う」などの丁寧語や謙譲語で品を出した。韓国語の笑いの表記`ㅎㅎ`を「ふふ」に替え、短く使う。人名の聞き違いを引用する例も、「勝てる」と「勝照さん」で成り立つように書き直した。
- `seosoyoung.rules.response_general`。応答の書式を定めるカードである。人物像、呼び方、口調の正本は`general.md`と明記した。
- `seosoyoung.rules_pas.pas_role`。インストール時の名称「ソ・ソヨン(PAS)」「ワークスペース」「日次まとめ」を使い、日次まとめの起動文と選択肢を日本語にした。固定のモデル例は、利用可能なプリセットをカタログから選ぶ指示に置き換えた。
- `seosoyoung.rules_pas.persistent_report`。PASが書く例文と選択肢には自然な日本語を使う。エスケープの指示は、`options`などのユーザー向け文言に共通する形に直した。カードの依頼の回答値と、PASが自分で書いた選択肢の違いを明記した。「[別件]」は報告上の慣例として日本語にした。

## 画面表示と送受信される値

- カードの依頼が使う「했어」は値として残す。画面表示は「対応しました」。PASが自分で作る報告ページの選択肢は入力した文言がそのまま表示されるため、日本語の「対応しました」を入れる。
- 「確認しました」は報告を閉じるボタンの表示。PASに届く確認の文言は`<タイトル>: 확인했어`、キャンセル依頼で届く文言は`<タイトル>: 답을 취소합니다`である。これらの値、サーバーが送るカード通知4種、注入される見出し「지금의 보고 (N장)」は保持した。
- 原文の「#번호 완료됨」は番号付きの完了通知の略記である。日本語では`persistent.completion.numbered`と`persistent.completion.done`を組み合わせて「#番号・完了済み」とした。

## 辞書にない名称・文言

- `seosoyoung.rules_pas.pas_role`。原文の「작업실」「일간 정리」はインストール時の名称で、本文では「ワークスペース」「日次まとめ」を使った。「켜기」「나중에」「끄기」はPAS独自の選択肢であり、「有効にする」「後で」「無効のまま」とした。「일간 정리 제안은 거절됨」は継続指示に書く記録で、「日次まとめの提案は見送り」とした。「폴더와 연결」はatomの「프로젝트」カード内の見出しで、「フォルダーに関連づける」とした。「저장소 연결 확인」は作成する確認項目の名前で、「リポジトリの接続確認」とした。
- `seosoyoung.rules_pas.persistent_report`。原文の「카드 장」は画面ラベルではなく、カードに連動する報告ページを指す用語である。「カードの報告ページ」とした。「카드 질문을 쓰는 법」「맡긴 카드의 알림을 받았을 때」「부수 수리 카드는 PAS가 완료한다」「담당이 보낸 별건을 받았을 때」はスキルや別カードの見出しへの参照であり、本文中では意味を訳した。
