# skills-aの日本語化ノート

## ロケールに合わせた変更

| カード | 変更と理由 |
|---|---|
| `skill.atom_tree_cleanup.body` | 保護対象の見出しを「作業履歴」「失敗事例」にそろえた。スキャン結果、目次案、判定例の文章を日本語にし、ツール呼び出しと操作キーは維持した。 |
| `skill.card_work.body` | 日本語版のプロフィール名「ソ・ソヨン(PAS)」を使う。常駐セッションはプロフィールで特定する。別件の接頭辞は`[別件]`、引き継ぎの見出しは「PASへ送信できなかった別件」とした。ユーザー発言の要約の前置きは日本語にした。発言者は`mode`に基づくサーバーの処理で決まり、前置きは記載上の慣例である。 |
| `skill.review_code.body` | Enterの確認を、韓国語入力に限らずIME変換中(`event.isComposing`)の入力に適用した。 |
| `skill.ui_design.body` | 日本語と中国語は既定の折り返しを使う。日本語では対応ブラウザーで`word-break: auto-phrase`も使える。`keep-all`は韓国語の文章に限り、長いURLや識別子を折り返す`overflow-wrap: anywhere`は全言語で使う。 |
| `skill.ui_css_recipes.body` | UIデザイン基準と同じ折り返し方針を適用した。日本語などを含む本文を等幅フォントにしない。CSSの例はコメントを日本語にし、宣言とセレクターは維持した。 |
| `skill.statechart.body` | Mermaidと差分図の表示ラベルを日本語にした。状態ID、構文、レンダラーが読む`(어긋남 N)`は維持した。 |

カードの状態名は`packages/i18n/GLOSSARY.ja.md`と`cards.json`の`status.*`に合わせた。依頼の回答値`했어`はそのままにし、画面表示「対応しました」を併記した。サーバーの通知見出し、実行プロンプトの`선행 카드`、ワークツリー割り当てのエラー抜粋も実際の出力に合わせた。

## 韓国語の原文と完全に一致するUI辞書値がない箇所

| カード | 韓国語 | 日本語本文での扱い |
|---|---|---|
| `skill.card_work.body` | 확인 요청: 제목 | プッシュ通知の接頭辞`확인 요청:`を保ち、「確認の依頼」と説明した。 |
| `skill.card_work.body` | 부탁: 제목 | プッシュ通知の接頭辞`부탁:`を保ち、「操作の依頼」と説明した。 |
| `skill.card_work.body` | {기다리는 것}, {시각}에 다시 확인 | 例の差し込み箇所名は日本語、サーバー出力の固定部分`에 다시 확인`は原文とし、「指定時刻に再確認」と説明した。 |
| `skill.card_work.body` | 담당이 바뀌어 자동 재개 예약을 해제했습니다 | サーバーが状況ボードに直接書く文を保ち、日本語で意味を添えた。 |
| `skill.card_work.body` | + 카드 | Webのプラスアイコンに対応する`cards.addCard`の実際のラベル「カード追加」を使った。韓国語辞書値は「카드 추가」である。 |
| `skill.ui_design.body` | 로딩 중 | 特定画面のラベルを指さない例なので「読み込み中」とした。 |
