# 简体中文角色指令翻译说明

## 按简体中文安装环境改写的卡片

- `seosoyoung.rules.general` 保留朝鲜王朝原型、显赫家族的继承人、异国学习魔法和秘密任务等设定。用礼貌、略带古雅、但读起来轻松的现代中文重写例句，以“承蒙”“还请”“方才”等日常可懂的用词带出语气。只允许“哈哈”作为随意的笑声，可重复书写。“呵呵”容易让人听出讥讽，因而避用。把误认人名的谐趣改成机器人把“胜算”当作人名。
- `seosoyoung.rules_pas.pas_role` 使用安装名称“工作区”“每日整理”和 Seo Soyoung (PAS)，翻译定期任务的提示词及 PAS 自拟选项。原文的模型举例取决于安装时点，改为从已登录后端中选标有 `available: true` 的预设，与英语、日语版本的处理一致。
- `seosoyoung.rules_pas.persistent_report` 将韩文转义规则推广至 `options` 等面向用户的文字，把 PAS 自拟的选项和对话示例译成中文。卡片请求仍使用服务器的请求答复值，PAS 自拟的请求选项则直接写“我已处理”。负责人另案的前缀采用“[另案]”，这是行文约定。原文引用了 `pas-role.md` 的三个章节。当前种子中尚无这些章节，译文照原文保留引用。

## 界面用语与运行时值

- 请求完成按钮是“我已处理”（`persistent.thread.didIt`、`cards.doneResponse`），发送时保留服务器值。报告确认按钮是“我已确认”（`persistent.thread.acknowledge`），发送确认或取消请求时保留原来的消息值和消息格式。首轮报告上下文保留服务器标题，并附中文释义。
- “补充”使用 `cards.appendAnswer`，选择后输入区使用 `persistent.expansion.appendTo`。“#{{number}} 已完成”由 `persistent.completion.numbered` 与 `persistent.completion.done` 组合。
- 字典中没有对应界面项的原文用语有“관리자 전용”（仅限管理员，权限说明）、“저장소 연결 확인”（确认仓库连接，示例检查项）、“켜기”“나중에”“끄기”（启用、稍后、不启用，PAS 自拟选项）、“응”“아니”“다른 안”（同意、不同意、其他方案，PAS 自拟选项）。这些用语按原意翻译。
- “작업실”“일간 정리”是安装名称，按基准文档译为“工作区”“每日整理”。“폴더와 연결”是项目种子卡片中的章节，按原意译为“关联文件夹”。
