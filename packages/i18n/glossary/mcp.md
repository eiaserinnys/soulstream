# MCP 용어

| 한국어 | English | 사용 맥락 |
| :--- | :--- | :--- |
| 비밀값, 비밀 | Secret | DB에 저장하거나 참조하는 인증 값. 탭 제목에는 복수형 Secrets를 쓴다. |
| 전송 방식 | Transport | MCP 서버 연결 방식. 설정에 쓰이는 프로토콜 값은 원문 그대로 표시한다. |
| 전송 이름 | Transport name | MCP 클라이언트에 전달되는 서버 이름. |
| 적용 노드 | Assigned nodes | 서버 정의를 적용할 노드. |
| 노드별 덮어쓰기 | Node override | 특정 노드에서 기본 서버 정의를 대신해 쓰는 정의. |
| 판 | Revision | DB와 노드의 적용 상태를 식별하는 번호. 좁은 상태 표시에는 Rev를 쓴다. |
