# Webhooks and access glossary

| 한국어 | English |
| :--- | :--- |
| 들어오는 웹훅, 인바운드 웹훅 | Inbound webhook |
| 나가는 웹훅, 아웃바운드 웹훅 | Outbound webhook |
| 대상 세션 | Target session |
| 발신자 이름 | Sender name |
| 키 | Key (Authorization: Bearer) |
| 서명 | Signature (Standard Webhooks) |
| 서명 비밀 | Signing secret |
| 받을 주소 | Callback URL |
| 확인 요청 | Verification request |
| 앞에 붙일 글, 머리말 | Preamble |
| 최근 요청 | Recent requests |
| 전달 기록 | Delivery history |
| 다음 시도 | Next try |
| 다시 보내기 | Resend |
| 접근 링크, 접속 링크 | Access link |
| 내 에이전트 | External agents (settings tab) |
| 연결 키 | Connection key |
| 기존 연결 | Existing connection |
| 만료 | Expiration |
| 폐기 | Revoke |
